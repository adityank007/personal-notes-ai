## Adding something new

1. Choose a category and create a descriptive folder following the [guide](CONTRIBUTING.md).
2. Copy a suitable template, fill it in, and include sources and a checked date.
3. Link it from the category index. Keep the main index concise.
4. Review for private information before publishing.

**Public repository:** do not store credentials, booking references, private contact information, precise accommodation details, or sensitive documents here. AI-assisted research can be incomplete or become outdated; linked sources and verification notes are part of each guide.
