## Add a note

Create `notes/topic/README.md` and link it here. Include its purpose, last-updated date, concise explanation and any sources. Larger topics can add descriptively named Markdown files and link them from their topic README.

Keep private journals and sensitive personal records out of this public repository. See the [organization guide](../CONTRIBUTING.md).
